# codefest-cluster-practice-2026

Practice runs for the STI Codefest 2026 cluster competition: a native Android MVP built in 6 hours from a business case (Kotlin + XML + ViewBinding + Room).

| Date | App | Case |
|---|---|---|
| 10-21-26 | [WasteApp](WasteApp%20-%2010-21-26) | Waste Segregation & Recycling Guide |
| 10-23-26 | [BayanQuest](BayanQuest%20-%2010-23-26) | Gamified community disaster preparedness |
| 10-26-26 | [TindaTrack](TindaTrack%20-%2010-26-26) | Sari-sari store inventory, POS & utang ledger |

Each folder has the Android Studio project and a `*_Practice_Pack` with the case prompt (plus seed data and assets when provided).
